Import Recurring Contracts
Upload the same report you get from "Download Report" below — matched rows land in Recurring Services Scheduler.
▸

Upload the same .xlsx the "Download Report" button below produces (columns: Contract #, Client, Frequency, Mon…Sun, Hours, Target, Tech 1/Tech 1 Hours/Day, Tech 2/Tech 2 Hours/Day…). Contract # is filled in automatically once a row's Client is matched — it's the real ClientID (like "GS-1001"), with a letter added ("GS-1001-A", "GS-1001-B"…) only if that same client already has another building in the matrix. Leave it blank on upload — it fills itself in. Mark a day with X (either case). Hours go as duration, "xx:xx" — 8 hours is "08:00", 4.5 hours is "04:30", not a time of day. Columns are matched automatically. Only Weekly contracts can be created today — RecurringServices doesn't support Biweekly/Monthly yet, those rows show up but stay blocked. Client and Tech always come from the real Clients/Techs lists, same as the regular Recurring form — nothing here is typed free-text into the system. The file stays loaded here once you upload it — you don't need to re-upload after saving a row.
